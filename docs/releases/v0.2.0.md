**RAUSNet 0.2.0: first desktop release.** Accessible app to grade synovitis (EULAR-OMERACT 0–3,
grey scale + Power Doppler, MCP 2–3 and wrist) and to improve the model with clinicians' corrections.

> **Research use only.** Not a medical device and not a diagnosis. The bundled model **v0005 was trained
> on synthetic images** (test combined QWK 0.993 on synthetic data) and is not validated on patients.
> Synovitis is the ultrasound sign of inflammation assessed in rheumatoid arthritis: the result supports
> the referral decision, it does not diagnose rheumatoid arthritis.

## Download (Windows 10/11, 64-bit)
`RAUSNet-0.2.0-windows-x64.zip`: unzip the whole folder and open `RAUSNet.exe`. No Python and no internet
needed. It is not signed: in Windows SmartScreen choose "More info" → "Run anyway". Check the download
against `RAUSNet-0.2.0-windows-x64.zip.sha256`. The folder includes `LEEME.txt`, a short guide in Spanish.

## What the app does
| Need | Where | How |
|---|---|---|
| **Predict on an image** | tab *Analizar* | drop the GS + PD images (or `Ctrl+O`) → *Analizar*: combined grade in number and word, GS and PD grades, confidence, referral warning, heat map, PDF report |
| **Feed the model** | *Analizar* → *Corregir etiqueta*; tab *Mejorar el modelo* | correct a grade in 3 clicks (undo with `Ctrl+Z`); corrections go to the workspace; *Mejorar en Colab* (or *Mejorar en este equipo* with an NVIDIA GPU in the source installation) trains and promotes a new version only if it is better |
| **Check model state and version** | top of the window; tab *Mejorar el modelo* | version in use, clinical-validation banner, global model version, date, quality in words, images waiting for the next improvement, run in progress, history and version table; lead option to roll back |

- **First start:** a local workspace is created from the bundled seed (model, dataset manifest, synthetic
  data recipe) in `%LOCALAPPDATA%\RAUSNet\desktop\workspace`.
- **Shared model for a team:** *Ajustes* → *Elegir carpeta…* → an empty Google Drive folder; the app sets
  it up with the bundled model, and every computer chooses that folder.

## Accessibility
- Keyboard shortcuts.
- Screen-reader names and spoken result.
- Text size up to 200 % (reaches every control), high contrast and a colour-blind-safe heat map.
- Fits a 1366 × 768 screen.
- Automated audit: 0 errors (`docs/paper/a11y_audit.md`).

## Install from source (all platforms, one command)
Windows PowerShell:
```powershell
irm https://raw.githubusercontent.com/JB-GB/AI_for_Biomedical_Engineers/PIA_devl/scripts/install.ps1 | iex
```
Linux / macOS:
```bash
curl -fsSL https://raw.githubusercontent.com/JB-GB/AI_for_Biomedical_Engineers/PIA_devl/scripts/install.sh | bash
```

## Changes since 0.1.0
- Interface phases F1–F5 (logbook M6-T6.6 to T6.10):
  - shared workspace and improvement panel;
  - accessible single-image flow;
  - 3-click corrections with undo;
  - local improvement with progress and cancel;
  - version history and roll back;
  - accessibility audit and fixes;
  - usability-study tools.
- Workspace seed and first-start local workspace; empty shared folders set up from the app.
- One-command installers (`scripts/install.ps1`, `scripts/install.sh`).

## Known limitations
- Model trained on synthetic data only; clinical data, validation and the usability study (SUS) are pending.
- The Windows bundle has no PyTorch: improvement runs on Colab (or in the source installation with a GPU).
- Windows bundle only; on Linux/macOS use the source installation.
