- **Author:** JB-GB

## Context
Build the config-driven baseline: two-head (GS, PD) network on a 4-channel input.

## Actions
- Metrics in numpy: QWK, balanced accuracy, per-class recall, AUC (grade ≥ 2), combined-grade probabilities.
- Dataset: GS + PD RGB → (4, H, W); missing PD → GS replicated and PD loss ignored.
- Model: timm backbone + GS head + PD head; combined grade derived by the scoring rule.
- Training: class-weighted CE, AdamW + cosine, AMP, early stopping on val combined QWK,
  `model_card.json` with provenance (stage, manifest hash, git commit, split sizes).
- Environment: PyTorch 2.14.1+cu126, timm 1.0.31, RTX 4070 Laptop detected.

## Findings / Results
- 61 unit tests pass, including a CPU end-to-end training smoke test.
- GPU run with `num_workers: 4` failed before epoch 1:
  1. `OpenBLAS error: Memory allocation still failed`.
  2. `WinError 1455` (page file too small) loading CUDA DLLs in each spawned worker.

## Blockers
- Windows multiprocessing data loading + CUDA DLL memory.

## Decisions
- Limit BLAS threads in workers; default `num_workers: 0`. Both unverified on GPU.
- Work paused (no power/internet). Resume guide: `docs/RESUME.md`.
