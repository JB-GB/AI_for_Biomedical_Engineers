## Actions
- **Exact Grad-CAM in the forward pass.** Both backbones end in global average pooling + linear
  head, so Grad-CAM equals CAM (Σ_k W[c,k]·A_k up to a positive constant). Verified against autograd
  Grad-CAM in tests. The ONNX graph now outputs `gs_cam` and `pd_cam` (N×4×7×7) → explanations at
  inference without gradients or PyTorch. Overlay: sequential warm ramp, transparent below 20 %.
- **API/app:** `/predict?explain=true` returns overlays as PNG data URLs; the desktop app has a
  "show heat map (Grad-CAM)" toggle.
- **Temperature scaling** per head fitted on the validation split (NLL, golden-section search);
  stored in `calibration.json` and in the ONNX sidecar; the API serves calibrated probabilities.
  Never changes the predicted grade.

## Results — calibration (v0003, test split 240 images)
| Head | ECE before → after | NLL before → after |
|---|---|---|
| GS (T = 0.40) | 0.045 → 0.032 | 0.132 → 0.140 |
| PD (T = 0.69) | 0.033 → 0.031 | 0.304 → 0.311 |
| Combined | **0.063 → 0.033** | 0.233 → 0.244 |

- **Correction:** T < 1 means the model was slightly *under*confident overall, not overconfident.
  The 100 % shown in the M6 screenshot was an easy example. Scaling halves ECE but slightly
  worsens NLL on test (sharper probabilities penalise the few confident errors) → report both.
- Low-confidence bins hold few images (6–17), so the reliability curve is noisy there.

## Results — Grad-CAM localisation (synthetic test images with synovitis, n = 162)
| Measure | Value | Chance / reference |
|---|---|---|
| Pointing game, GS head (peak inside synovium ± 1 CAM cell) | **98.8 %** | 8.0 % (dilated-mask area) |
| Pointing game, PD head (PD ≥ 1) | **99.1 %** | 8.0 % |
| CAM energy inside synovium, GS head | 7.4 % | 1.0 % (mask area) → 7.6× enrichment |
| CAM energy inside synovium, PD head | 8.9 % | 1.0 % → 9.2× |

- Energy ratios are bounded by the coarse 7×7 CAM grid (one cell ≈ 37 px vs a synovium of ~1 % of the image).

## Findings — PD false positives (25 test images with predicted PD > true PD)
- **The M3 hypothesis (distractor vessel) is mostly rejected:** only 6/25 contain the
  out-of-synovium vessel (24 % vs 16 % base rate), and in the example figure the PD CAM stays on
  the synovium, not on the vessel.
- Breakdown: 9 PD0→1 and 8 PD1→2 (one-grade over-calls, mostly GS1 joints), 1 PD2→3, and
  **7 PD0→3, of which 5 are GS0 images** (no synovium: PD head output is unconstrained there).
  The combined rule (GS 0 → 0) neutralises those unless the GS head also errs (1 case → the 0→3
  combined error seen in M3).

## Decisions
- Keep CAMs and calibration as part of every export.
- Proposed (M4 backlog): train the PD head only where GS ≥ 1 (mask PD loss on GS0) or add a
  consistency term, so PD is undefined rather than arbitrary without synovium.

## Paper notes
"Because the backbone ends in global average pooling followed by linear heads, Grad-CAM
reduces exactly to class activation mapping and was computed in the exported inference graph.
On synthetic test images the CAM peak fell inside the synovial region (±1 feature cell) in 98.8 %
(GS) and 99.1 % (PD) of cases versus a chance level of 8 %. Temperature scaling fitted on the
validation split reduced the combined-grade expected calibration error from 0.063 to 0.033."
