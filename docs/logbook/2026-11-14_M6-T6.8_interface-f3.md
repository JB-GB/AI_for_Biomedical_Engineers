## Actions
- **One click per grade:**
  - GS and PD corrections use 4 radio buttons each, labelled with number and word, pre-selected
    with the AI grades after each analysis. Arrow keys move inside a group; Tab reaches it once.
  - A correction is 3 clicks: GS grade, PD grade, `Enviar corrección`.
  - Decision: the pre-filled panel stays visible instead of opening a dialog, which saves a click
    and keeps the result in view while correcting.
- **Sending:**
  - Sending the AI's own grades is recorded as a *confirmation* (also a useful label).
  - The send button turns off after sending, so the same case is not sent twice. If you change a
    grade and send again, the new label replaces the previous one.
- **Undo (`Deshacer`, `Ctrl+Z`):**
  - The API removes the manifest row, then the images.
  - It refuses (409) once any `datasets/*/manifest.csv` contains the image, because a trained
    model's dataset must stay reproducible.
  - Only ids of the form `corr-<12 hex>` are accepted, so paths cannot be injected.
- **Pseudonym checked in the app:** a missing or invalid pseudonym (for example a name) gets a
  plain message and focus moves to the field. Before, this showed the raw 422 JSON from the API.
- **"Casos de hoy":**
  - every analysis and correction on this computer, newest first, with a count of corrections;
  - holds time, pseudonym, joint, side and grades only, never file names or paths (they can
    contain names);
  - stored in the user's local app data (`RAUSNET_CASES_FILE` overrides) and emptied on a new day.
- **Input checks when images are loaded,** shown under the images and announced:
  - *Blocking:* GS/PD sizes differ, side < 64 px, file > 20 MB, unreadable. They stop analyse
    and send with the reason.
  - *Warnings:* colour in the GS slot (swapped images?), no colour in the PD slot (normal
    without Doppler signal; otherwise check).

## Results
- 6 new UI tests plus 1 API test, 175 tests in total pass:
  - correction in 3 real mouse clicks, stored with the right grades, then undone (files and row gone);
  - re-send replaces and a confirmation is recorded;
  - undo refused once in a dataset;
  - missing or name-like pseudonym explained, nothing sent;
  - today's cases file has only the allowed fields and no file names, survives a restart and resets daily;
  - every input check, and blocking checks stop analyse and send.
