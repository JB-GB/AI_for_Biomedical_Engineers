## Actions
- **T6.5 Docker:** CPU-only image (`.[serve]`, no PyTorch), non-root, `/health` healthcheck, registry
  mounted read-only; compose binds `127.0.0.1`, read-only root FS, all capabilities dropped.
- **T6.5 Windows bundle:** PyInstaller one-folder build (no torch), models outside the bundle; build script
  runs `--self-test` (imports, loads the current model, starts the local API).
- **T6.1 PDF report:** desktop button after an analysis; grades + confidence, inputs and Grad-CAM overlays,
  refer warning, model version, pseudonym if entered, disclaimer (decision support, to be confirmed by a
  rheumatologist), ES/EN. Rendered with Qt (no new dependency).
- **Retrain post-processing:** a promoted model is calibrated and exported in the same command;
  failures are recorded in the report and never undo the promotion (`--no-postprocess` to skip). The
  runner workflow no longer duplicates the step; Colab installs what export needs.
- **T2.1 De-identification (`rausnet-deid`):** pixel re-encoding (no EXIF/text chunks/DICOM tags), device
  crop presets + black-out boxes, HMAC-SHA256 pseudonyms with a salt kept outside the repo, refuses outputs
  inside a git repo, audit log without identifiers, no ID↔file mapping written.
- **T2.4 EDA (`scripts/eda.py`):** class balance per split/source/joint, image stats, PD colour fraction.
- **T8.3 Manuscript draft v0.1** assembled from logbook paper notes; clinical parts `[TBD]`.
- The four code tasks were developed in parallel and integrated/reviewed one by one.
