# [2026-11-13] M4-T4.1 — PD on joints without synovium: scoring rule + loss masking

- **Author:** JB-GB
- **Type:** Result / Decision
- **Related:** `metrics.consistent_pd_probabilities`, `train.pd_mask_gs0`, `evaluate.py` (`pd`, `pd_raw`),
  `calibrate.py`, `serve/inference.py`, `scripts/analyze_cam.py`; models v0003 → **v0004**;
  figure `calibration_v0004.png`; local results `models/v0004/{retrain_report,ablation_pd_mask,calibration,cam_analysis}.json`.
  Follows up the PD false-positive analysis in entry M4-T4.4.

## Actions
- **Scoring rule at inference** (EULAR-OMERACT: PD > 0 needs synovium). PD probabilities become
  P(PD = d) = P(GS = 0)·[d = 0] + P(GS ≥ 1)·p_PD(d). Served by the API/app and used for PD metrics
  (`pd`); the bare head is still reported as `pd_raw`. Combined grade is unchanged (it already applied the rule).
- **PD loss masking** (`train.pd_mask_gs0: true`, now default): GS 0 joints give no PD loss; PD class
  weights and the PD temperature are computed on GS ≥ 1 joints only.
- **Retraining v0004:** + `incoming/batch_002` (60 new synthetic patients, seed 2, 360 images),
  fine-tuned from v0003 for 10 epochs with masking; promotion by paired bootstrap.
- **Ablation:** identical fine-tune and data **without** masking (outside the registry).

## Results — rule alone (v0003, its own test split, 240 images / 40 patients)
| | PD QWK | PD false positives | of which GS 0 |
|---|---|---|---|
| Bare PD head | 0.807 | 25 | 5 |
| With GS 0 → PD 0 rule | **0.950** | 18 | **0** |

## Results — v0004 test split (282 images / 47 patients, frozen salt)
| Model | Combined QWK | GS QWK | PD QWK (rule) | PD QWK (raw) | PD FP (rule) |
|---|---|---|---|---|---|
| v0003 (parent) | 0.904 | 0.964 | 0.956 | 0.825 | 20 |
| Ablation: + batch_002, no mask | 0.942 | 0.979 | 0.974 | 0.841 | 9 |
| **v0004: + batch_002, mask** | **0.945** | 0.983 | 0.970 | 0.843 | 9 |

- Promotion: v0004 − v0003 combined QWK **+0.041, 95 % CI [+0.008, +0.090]** → promoted
  (significantly better, not only "not worse").
- Mask vs no mask (paired bootstrap): combined **+0.003 [−0.003, +0.011]**, PD (rule)
  **−0.004 [−0.021, +0.006]** → **no measurable effect of masking.** The gain over v0003 comes from the
  extra data; the GS 0 false positives are removed by the rule.
- Grad-CAM (v0004, 192 synovitis images): pointing game GS 97.4 %, PD 99.3 % (chance 8.2 %);
  PD false positives 25 → 9 (2 with the distractor vessel, base rate 16 %).
- Calibration (v0004): T_GS = 0.45, T_PD = 0.74. Test combined ECE **0.021 → 0.022**, NLL 0.182 → 0.197:
  v0004 is already well calibrated and temperature scaling fitted on 300 validation images
  **does not help on test** (it did for v0003: 0.063 → 0.033). Low-confidence bins hold very few images.

## Decisions
- Keep the GS 0 → PD 0 rule everywhere a PD grade is shown or scored (clinical definition, large effect).
- Keep `pd_mask_gs0: true`: neutral on metrics but removes a meaningless training target; report as
  "no significant effect" in the paper (ablation above).
- Keep temperature scaling in the pipeline but report before/after; reconsider applying it only when
  validation evidence is stronger (larger validation set or cross-validated temperature).

## Paper notes
"Because power Doppler is scored only in the presence of synovial hypertrophy, PD probabilities were
conditioned on the GS prediction (P(PD=0) absorbs P(GS=0)). This raised PD QWK from 0.807 to 0.950 on
the same model. Masking the PD loss on GS-0 joints had no significant effect (ΔQWK combined +0.003,
95 % CI −0.003 to +0.011)."
