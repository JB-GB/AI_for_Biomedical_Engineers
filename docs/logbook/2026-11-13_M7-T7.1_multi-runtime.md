## Actions
- **T7.1 Local:** `python scripts/setup_env.py [--cpu]` builds the venv, installs PyTorch (CUDA 12.6 or CPU
  wheels) and all extras, activates the commit hook. Tested in a fresh throwaway venv with
  `--cpu --extras serve` → `rausnet 0.1.0 | torch 2.15.0+cpu`.
- **Resumable training** (needed for Colab): `last.pt` (model, optimiser, scheduler, scaler, history)
  written atomically every epoch; `python -m rausnet.train --resume <run_dir>`. Test simulates a
  disconnect after epoch 1 of 2.
- **T7.2 Colab:** `notebooks/colab_train.ipynb` — read-only clone of `PIA_devl`, Drive mount, synthetic
  or Drive data copied to local disk, train (auto-resume of the newest unfinished run) or retrain
  (registry on Drive), numbers-only results, `runtime.unassign()` at the end. `tests/test_notebooks.py`
  rejects committed outputs, execution counts, token-like strings and `share=True`.
- **T7.3 Runner:** `train-self-hosted.yml` — `workflow_dispatch` only (public repo), runner labels
  `[self-hosted, gpu, rausnet]`, read-only token, inputs via env vars (no script injection), registry
  and data outside the workspace (repository variables), calibrate + export when a retrain promotes,
  uploads metrics only. `ci.yml` runs ruff + pytest on GitHub-hosted Ubuntu with CPU torch.
- **T7.4 Equivalence:** `scripts/compare_runs.py` checks same manifest hash and split sizes and runs a
  paired patient-level bootstrap on the test split. `RAUSNET_DEVICE=cpu` added because an empty
  `CUDA_VISIBLE_DEVICES` is ignored on Windows (first "CPU" run silently used the GPU; caught by the
  device field of the model card).

## Results — local CPU vs GPU (smoke config: ResNet-18, 128 px, 10 epochs, same seed, synthetic test 198 images / 33 patients)
| Run | Device | Best epoch | Test combined QWK |
|---|---|---|---|
| A | i7-13700HX (CPU) | 9 | 0.935 |
| B | RTX 4070 Laptop (CUDA, AMP) | 7 | 0.944 |

- Same data (manifest SHA-256 and split sizes identical). Difference B − A **+0.009, 95 % CI
  [−0.018, +0.036]** → equivalent at this sample size.
- Two GPU runs with the same seed also differed (best epoch 9 vs 7; QWK 0.933 vs 0.944, CI contains 0):
  training is **not bit-reproducible** (non-deterministic CUDA kernels, AMP), so equivalence must be
  judged statistically, never by identical weights.
