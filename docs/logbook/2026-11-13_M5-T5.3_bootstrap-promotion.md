# [2026-11-13] M5-T5.3 — Paired bootstrap promotion rule and confidence intervals

- **Author:** JB-GB
- **Type:** Decision / Result
- **Related:** `src/rausnet/metrics.py` (`bootstrap_ci`, `paired_bootstrap`), `retrain.py`,
  `evaluate.py`, `configs/retrain/default.yaml`; previous entry M5-T5.2

## Context
With a fixed tolerance of 0, v0002 was rejected for a 3-image difference (QWK 0.894 vs 0.898),
i.e. noise. Decision taken with the team: switch to a statistical rule before M6.

## Actions
- **Patient-level (cluster) bootstrap:** patients are resampled with replacement and all their
  images move together (6 images/patient are correlated). 2 000 resamples, seed 0, percentile CI.
- `evaluate` now reports `qwk_ci95` for the combined grade.
- **Promotion rule `bootstrap` (new default):** paired bootstrap of
  QWK(candidate) − QWK(current) on the same frozen test images; the candidate is **rejected only
  if the whole 95 % CI is below 0** (significantly worse). `tolerance` rule kept as an option.
- Retrain report stores the bootstrap result (`paired_bootstrap`) and per-model CIs.

## Results
| Model / comparison | Combined QWK | 95 % CI |
|---|---|---|
| Baseline v0001 on original test split (198 img, 33 patients) | 0.908 | [0.819, 0.968] |
| v0001 on expanded test split (240 img, 40 patients) | 0.898 | [0.810, 0.961] |
| v0003 candidate (+ batch_001, fine-tuned) same split | 0.894 | [0.804, 0.957] |
| **Paired difference v0003 − v0001** | **−0.004** | **[−0.015, +0.004]** → PROMOTED |

- v0003 reproduced v0002 exactly (same QWK to 4 decimals): fine-tuning is deterministic with a fixed seed.
- Single-model CIs are wide (~±0.07) with 33–40 test patients, while the **paired** CI is ~10× narrower
  because both models are scored on the same patients — pairing is what makes the comparison meaningful.
- Registry: v0001 archived, v0002 rejected (old rule), v0003 current. 76 unit tests pass.

## Decisions
- Default promotion rule: paired bootstrap, α = 0.05, 2 000 resamples.
- Report every headline metric in the paper with a patient-level 95 % bootstrap CI.

## Limitations
- "Not significantly worse" is not "non-inferior": with few test patients a real small drop can
  pass. Once hospital data exist, consider a non-inferiority margin (e.g. reject if CI low < −0.05)
  and `promotion.sources: [hospital]`.
