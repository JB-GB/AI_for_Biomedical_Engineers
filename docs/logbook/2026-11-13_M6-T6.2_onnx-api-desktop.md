# [2026-11-13] M6 — ONNX export, inference API and desktop client

- **Author:** JB-GB
- **Type:** Result

## Context
Option B (ADR-001): ONNX is the only contract between training and serving; clinicians use a
desktop app; other engineers can reuse the HTTP API (web client, hospital integration).

## Actions
- **Export:** `python -m rausnet.export` converts the registry's current model to `model.onnx`
  (opset 17, dynamic batch) + `model.json` sidecar (version, stage, `clinically_validated: false`,
  intended use, input spec, combined rule, dataset hash, test metrics). Parity check vs PyTorch.
- **Inference without PyTorch:** numpy/PIL preprocessing re-implements the training resize
  (bilinear, align_corners=False, no antialias) in float32 → matches torch to ~2e-7.
- **API (FastAPI, localhost by default):** `/health`, `/model`, `/predict` (GS required, PD optional),
  `/corrections` (stores re-encoded PNGs + manifest in `incoming/corrections/<date>/`, directly
  consumable by `rausnet.retrain`). Patient IDs must be pseudonyms (`[A-Za-z0-9_-]`, no spaces);
  20 MB upload limit; invalid images → 422; corrections disabled without a data dir → 503.
- **Desktop app (PySide6):** `rausnet-desktop` starts a private local API on a free port and opens
  the window. Spanish (default) / English. Red banner when the model is not clinically validated,
  grade + confidence + probability bars, localized warnings (API returns warning codes),
  "submit correction" form pre-filled with the prediction.

## Results
- ONNX vs PyTorch max |logit diff| = 1.7e-6 (v0003, EfficientNet-B0, 16 MB).
- CPU inference via ONNX Runtime: ~35 ms per image pair on the laptop.
- End-to-end check (real uvicorn process + v0003): example GS2/PD1 image → combined grade 2.
- 94 unit tests pass (API via TestClient, GUI offscreen, correction → retrain manifest round trip).

## Findings / Blockers
- Qt `offscreen` platform on Windows renders broken glyphs; screenshots use the native platform
  with `grab()` (window never shown).
- Synthetic-trained model reports ~100 % confidence → overconfident by construction; calibration
  (M4-T4.5) is needed before showing confidence to clinicians on real data.
- `torch.onnx.export(dynamo=False)` emits a deprecation warning; works on torch 2.14.

## Paper notes
"The trained network was exported to ONNX and served by a lightweight FastAPI service
(ONNX Runtime, no deep-learning framework at inference, ~35 ms per image pair on CPU). A
desktop client lets non-technical users grade an image pair and submit corrected labels,
which are stored as a versioned manifest for the next retraining cycle."
