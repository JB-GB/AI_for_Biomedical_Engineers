## Goal
A release whose interface can (1) feed the model, (2) predict on an image and (3) show the state and
version of the model, plus a one-command installation from the terminal.

## Decisions
- **Workspace seed instead of a bare model.**
  - Problem: a release with only `models/` can predict, but cannot feed the model until someone runs
    Colab or `improve init`. `init` also needs the dataset manifest of the current model.
  - Finding: the v0005 dataset (1920 images) comes from three deterministic synthetic sets (seed 0 /
    200 patients, seeds 1 and 2 / 60 patients each). The batches regenerate byte for byte (manifest
    SHA-256 and images compared).
  - So `release/workspace` ships the model, the dataset manifest (SHA matches the registry) and the
    generator spec, about 32 MB. `workspace.json` now accepts a list of synthetic sets.
- **First start = local workspace from the seed** (`%LOCALAPPDATA%\RAUSNet\desktop\workspace`). All
  three functions work offline at once.
- **Empty shared folder = set up from the seed** after one confirmation in *Ajustes*. Starting a team's
  global model on Google Drive no longer needs Colab first.
- **Release built by GitHub Actions on a version tag**, using the workflow's own token: no personal
  token is handled. The tag must equal the package version, and notes must exist in `docs/releases/`.
  Published as a pre-release, because the model is synthetic-only.
- **Version 0.2.0** (pyproject and `rausnet.__version__`).
- **Installers:**
  - `install.ps1` (works through `irm … | iex`) and `install.sh` (`curl … | bash`);
  - they find Python 3.11+ and Git, clone or update `PIA_devl`, and pick CUDA or CPU PyTorch from
    `nvidia-smi` (`RAUSNET_APP_ONLY=1` installs the app only);
  - then they check that the bundled model loads and, on Windows, add a desktop shortcut;
  - failures use `throw`, not `exit`, so `iex` never closes the user's window.

## Results
- Local build: 213 MB folder, **116 MB zip**. The frozen self-test passed: seed → workspace → API v0005,
  status and versions read.
- **Real improvement on a seeded workspace:** 1920 images regenerated, 24 corrections, fine-tune,
  promotion ("not significantly worse", +0.0036 [−0.0019, +0.0111]), calibration, ONNX export, 3.3 min
  on the RTX 4070 laptop.
- 8 new tests (`tests/test_release.py`) plus a registry test. 203 tests pass.
  - seed complete, provenance hash, every image regenerable from the spec;
  - seeding once, status after seeding, several synthetic sets;
  - guide sections and version consistency;
  - `seed_dir` (source tree, `RAUSNET_SEED`);
  - empty folder offered and set up (No leaves it untouched);
  - build helpers (seed copy, zip layout, SHA-256).
- `install.ps1` parses in PowerShell 7 and 5.1 (ASCII only). The `param()` block works under `iex`.
  `install.sh` passes `bash -n`.
