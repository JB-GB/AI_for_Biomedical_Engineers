## Actions
- **Drag and drop:**
  - Drop both images anywhere on the window (or use `Ctrl+O`). GS and PD are told apart:
    1. by file or folder name (`pd`, `doppler`, `power`, `color` / `gs`, `grey`, `bmode`…);
    2. otherwise by colour content (Doppler signal, colour box or scale bar).
  - If neither decides, the order is kept and the app asks the user to check.
  - One image dropped on a slot goes to that slot.
  - Non-image files get a plain message, not an error.
- **Keyboard:**
  - Shortcuts: `Ctrl+Intro` analyse, `Ctrl+O` open, `Ctrl+P` PDF, `Ctrl+K` correct, `F1` help.
    They are shown on the buttons and in the status bar.
  - The tab order follows the task.
  - Visible focus: a 3 px blue frame, yellow in high contrast.
- **Screen readers:**
  - Every control has an accessible name.
  - After analysing, one sentence ("Grado combinado 3, grave. Confianza muy alta, 100 %. No requiere
    derivación.") gets keyboard focus and is announced with `QAccessibleAnnouncementEvent` (Qt 6.12).
- **Never colour alone:**
  - grades shown as number + word (0 normal, 1 leve, 2 moderada, 3 grave), also in the correction lists;
  - confidence shown as word + %;
  - a referral banner with icon and text.
- **Readable:**
  - text size 100–200 % in Ajustes, scaling every font, including the large grade;
  - high-contrast theme;
  - controls at least 44 px high;
  - colours set in one style sheet by object name. In the standard theme, text contrast is
    at least 4.5:1 and borders at least 3:1.
- **Heat map:** new `cividis` palette (blue to yellow, colour-blind safe, distinct from the
  red/yellow Doppler signal), via `?palette=cividis` on `/predict`.
- **Preferences:** remembered per user (`QSettings`). Tests write them to a temporary INI file,
  never to the registry.

## Results
- 7 new tests (`tests/test_accessibility.py`) plus palette tests in `test_explain.py` and `test_api.py`:
  - pairing by name, folder and colour;
  - words and the spoken sentence;
  - every control named and at least 44 px;
  - tab order;
  - keyboard-only check of one case (load → `Ctrl+Intro` → focus on the result → `Ctrl+K` → `F1`);
  - drop on the window and on a slot;
  - text size, contrast and palette applied and remembered.
- 168 tests pass.
- With the real model: focus lands on the result after analysing and on the GS correction after `Ctrl+K`.
  Screenshots of both themes are in `docs/paper/figures/`.

## Correction during the work
- First colour check missed PD images: synthetic PD images of grade 0 have no Doppler signal at all.
  The check is now on full-resolution pixels (6 coloured pixels are enough). Grey-only pairs are
  reported as a guess instead of being assigned silently.
