## Actions
- **T4.6 k-fold CV** (`python -m rausnet.cv`): 5 patient-level folds (hash, own salt) over the development
  pool only (train + val, 1638 images); test never touched. Fold i trains on 3 folds, early-stops on fold
  i+1, predicts fold i → out-of-fold (OOF) predictions for every development image; paired patient-level
  bootstrap of every recipe against the reference on the same images.
- **T4.2 US augmentation** (`data.augment: us`): rotation ±10°, zoom 0.75–1, depth gain ramp (TGC) ±25 %,
  gamma 0.7–1.4, multiplicative gamma speckle, Doppler gain 0.75–1.25. Every transform keeps the grade.
- **T4.3 backbones:** EfficientNet-B0, ResNet-34, ConvNeXt-nano, DeiT-small (ViT), 15 epochs, patience 4.
- **T4.5 refer to specialist:** lowest confidence threshold whose accepted validation cases reach a target
  accuracy (98 %, clinical choice); served as `refer: true` with a warning in the app (ES/EN). It never
  changes the grade.
- **Calibration gating:** temperature kept only if a 2-fold patient cross-fit beats T = 1 and the fit is
  not degenerate (see below).
- **`retrain --from-scratch`:** a new recipe goes through the normal registry and promotion rule.

## Finding — the basic augmentation was handicapping every model since v0001
- First CV runs and a from-scratch retrain **collapsed to chance on validation**. Diagnosis: the same model
  scored QWK 0.91 when noise was added at evaluation and 0.10 on clean images. Cause: Gaussian noise of a
  **fixed** level (σ = 0.02, always on) — the network learned to rely on it. Blur and GS/PD-identity
  hypotheses were tested and rejected.
- Fix: random level σ ~ U(0, 0.03), one field for GS and one shared by the PD RGB channels. Validation QWK
  0.96 after epoch 1. v0001–v0004 were trained with the bug (per-channel noise only partly masked it).

## Results — 5-fold CV, OOF combined QWK (1638 images / 273 patients)
| Recipe | OOF QWK [95 % CI] | Δ vs b0_basic [paired 95 % CI] |
|---|---|---|
| **EfficientNet-B0, basic aug (reference)** | **0.991** [0.987, 0.994] | — |
| ConvNeXt-nano, US aug, lr 1e-4 | 0.991 [0.987, 0.994] | +0.000 [−0.004, +0.004] |
| EfficientNet-B0, basic aug, no PD mask | 0.990 [0.986, 0.993] | −0.001 [−0.003, +0.001] |
| ResNet-34, US aug | 0.985 [0.981, 0.989] | −0.006 [−0.010, −0.001] |
| DeiT-small, US aug | 0.984 [0.979, 0.988] | −0.007 [−0.012, −0.003] |
| EfficientNet-B0, US aug | 0.979 [0.974, 0.984] | −0.012 [−0.017, −0.007] |

- ConvNeXt at the default lr 3e-4 stayed at chance loss (2·ln 4) in all folds; it could not even overfit
  32 images, while it did at 1e-4 → rerun at 1e-4 (reported above). Not an architecture result.
- US augmentation **hurts** on synthetic data (−0.012 for B0): the synthetic generator has little
  acquisition variability, so the extra invariance costs capacity without a benefit. It must be re-tested
  on real images, where probe angle, gain and depth do vary.
- PD loss masking: no effect from scratch either (−0.001, CI contains 0).
- Synthetic data are close to saturation (≈ 0.99); differences of < 0.01 matter statistically but not
  clinically. Recipe ranking must be repeated on S1/S3 data.

## Results — v0005 (B0, basic aug fixed, from scratch, same data as v0004), frozen test 282 images / 47 patients
| Model | Combined QWK [95 % CI] | GS QWK | PD QWK (rule) | PD FP |
|---|---|---|---|---|
| v0004 (fine-tune lineage with the bug) | 0.945 | 0.983 | 0.970 | 9 |
| **v0005** | **0.993** [0.984, 0.998] | 1.000 | 0.992 | 3 |

- Promotion: **+0.047, 95 % CI [+0.015, +0.098]** → promoted. Grad-CAM pointing game GS 100 %, PD 100 %
  (chance 8 %); 3 PD false positives (1 with the distractor vessel).
- **Calibration:** GS validation predictions are perfectly separated → NLL has no minimum, the fit ran to
  the search bound (T = 0.05) and *passed* the cross-fit gate (both halves separable). Added
  `degenerate_fit`: reject when every fitting prediction is correct or T is on a bound → T_GS = 1.
  T_PD = 1.30 passes; test combined ECE 0.013 → 0.018 (≈ 4 errors in 282 images: noise).
- **Referral (98 % target):** threshold 0.505, test coverage 100 %, accuracy 0.986, 1 case referred. The
  model already exceeds the target, so the threshold is inactive on synthetic data. On v0004 the
  validation-chosen threshold was optimistic (98 % on val → 96 % on test, 97 % coverage).

## Decisions
- Production recipe stays **EfficientNet-B0 + basic augmentation** (ties ConvNeXt; smaller, faster, exact
  CAM + ONNX path validated). ViT (DeiT) is lower and would need a different CAM method.
- Keep `us` augmentation as an option; re-evaluate with real data before using it.
- Temperatures only through the gate (cross-fit + degenerate-fit check). Referral target 98 % as default,
  to be set with the rheumatologists; report coverage and accepted/referred accuracy, never a bare threshold.
- Backbone-specific learning rates are needed when comparing families (ConvNeXt 1e-4).

## Paper notes
"Recipes were selected by patient-level 5-fold cross-validation on the development set (test untouched).
EfficientNet-B0 and ConvNeXt-nano tied (OOF QWK 0.991); ResNet-34 and DeiT-small were lower (Δ −0.006 and
−0.007, paired 95 % CIs excluding 0). A fixed-level noise augmentation made the network depend on the noise
(clean-image QWK 0.10); randomising the level fixed it and raised test QWK from 0.945 to 0.993 (Δ +0.047,
95 % CI +0.015 to +0.098). Temperature scaling was applied only when a patient-level cross-fit improved NLL
and the validation data were not perfectly separated."
